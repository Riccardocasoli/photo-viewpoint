From field survey to printed map

Three clicks

Set position, bearing and field of view. Label the viewpoint and link the original photograph.

Photographic context

Preview images, open their folder, replace links and read available GPS/EXIF fields without changing the manually drawn viewpoint.

Layout callouts

Generate photo frames and point leaders. Move and resize images, add descriptions and save page coordinates and dimensions in the layer.

Start from photos, too

Batch-import photographs using their GPS positions, or keep records without geometry in a manual-placement queue. Visible defaults define the initial field of view. The distGPS field tracks displacement from the original GPS position without changing source metadata.

Your data, your files

Create a temporary layer or a new GeoPackage, Shapefile, SQLite or FlatGeobuf dataset where supported. Default layer name: Photo viewpoint. The plugin keeps image references rather than copying or uploading photographs.

Languages and requirements

English interface; English and Italian manuals. Target: QGIS 3.28–3.44 with Qt 5 and a projected CRS in metres. QGIS 4 is not supported. Newly added functions require desktop testing before public release.

Portable styles and documentation

Choose classic rays, an oriented top-view camera, a bearing arrow or translucent FOV. Save QML or a supported database default style for reuse across projects. New layers use code, caption and distGPS first; legacy layers can be copied safely to an English-field GeoPackage.

Getting started

  1. Obtain the installable ZIP from the maintainer once a real release is available.
  2. In QGIS select Plugins → Manage and Install Plugins → Install from ZIP.
  3. Create a layer, choose a CRS and storage, then capture and name a viewpoint.

The source package contains a README, Italian manual, layout guide, EXIF field reference, tests and release instructions.
